# Requirements Generator — Setup Guide

## Install dependencies
```
pip install langgraph langchain langchain-google-genai fastapi uvicorn python-dotenv
```

## Environment variables
Create a `.env` file in the project root:
```
GOOGLE_API_KEY=your_gemini_api_key_here
```
Get your free Gemini API key at: https://aistudio.google.com/app/apikey

## Run locally
```
# Test the pipeline directly
python requirements_pipeline.py

# Start the API server
uvicorn api:app --reload
```

API docs available at: http://localhost:8000/docs (auto-generated by FastAPI)

## Project structure
```
├── requirements_pipeline.py   # LangGraph agents
├── api.py                     # FastAPI wrapper
├── requirements.txt           # Dependencies
└── .env                       # API keys (never commit this)
```

## requirements.txt
```
langgraph
langchain
langchain-google-genai
fastapi
uvicorn
python-dotenv
```
